# Dekorasi Check Mail

Ikon PNG transparan ini dipotong dari gambar-gambar yang diberikan pemilik proyek. Sebagian menjadi dekorasi di tepi kontainer dashboard; dua aset pada `hasil-scan/` hanya muncul di kartu hasil setelah email diperiksa. Semuanya dekoratif, bukan tombol, dan tidak menghalangi interaksi.

Dekorasi ditempatkan absolut pada kontainer panel terkait, sehingga ikut bergulir bersama panel. Posisi menempel dekat sudut/tepi luar kontainer agar tidak menutup teks atau kontrol. Animasi mengambang dan putar lambat diterapkan selektif melalui CSS; stiker disembunyikan pada layar sempit dan gerak dinonaktifkan bila perangkat mengaktifkan pengurangan animasi. Elemen di kartu hasil tetap diam.

File PNG lain dalam folder dapat dipakai untuk variasi dekorasi selanjutnya. `preview-stiker.jpg` menampilkan potongan ikon di atas latar gelap.
